🛠️ How to Use P2P Drop

It is incredibly simple and works across all devices (Android, iOS, Windows, Mac) right in your web browser.

1 Initiate the Transfer

  1. Open the Nothing Space Hub on the sending device.
  2. Scroll down to the File Drop (P2P) section.
  3. Select the file(s) you want to share from your gallery or file manager.

2 Share the Connection

  1. Once selected, the tool generates a unique, secure link or QR code.
  2. Share this link with the receiver via WhatsApp, text, or email.

3 Direct Streaming

  1. The receiver opens the link on their device.
  2. Important: Ensure both devices keep the browser tab open!
  3. The file will stream directly at maximum Wi-Fi/Data speeds and save locally once it hits 100%.
